# Boarding House Management System

A dashboard application with CRUD functionality for managing rooms, tenants, and payments.

## Group Members
- Dwayne Lloyd Villanueva
- Joe Kristian Muele
- Eugene Quilla
- Rhea Mae Baita

## Tech Stack
- Backend: Express.js (Node.js)
- Database: SQLite (better-sqlite3)
- Frontend: HTML, CSS, JavaScript

## Features
- Dashboard with statistics (rooms, tenants, collected payments, unpaid tenants)
- Rooms, Tenants, and Payments: add, edit, delete, search
- Room capacity limit: a full room can't accept more tenants
- Payment bill showing the tenant's room rate and balance
